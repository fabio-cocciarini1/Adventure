# 📌 Adventure

Adventure è un semplice gioco rpg in cui l'obiettivo è sconfiggere più nemici
possibili.

---

## 🚀 Come eseguire il progetto

### Prerequisiti
- Java 25 (LTS)
- Gradle

### Istruzioni

```bash
git clone https://github.com/fabio-cocciarini1/Adventure.git
cd Adventure
```

### Build del progetto
```bash
./gradlew build
```

### Esecuzione
```bash
./gradlew run
```
